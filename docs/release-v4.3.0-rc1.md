## 费曼物理 v4.3.0-rc1（内容与学习证据开发候选）

三端共用本次更新：Android 学生端、Android 教师端和 Windows。无需激活码即可打开学习；教师本机 PIN 与班级服务端权限仍保留。

- 修正密度切块题数量与解析比例不一致；旧题修订留存，用户编辑不覆盖，新作答保留题目快照，旧作答不自动重评分。
- 独立练习支持本机草稿自动保存与退出恢复；按学生和题目隔离，草稿不计学习证据。
- 教师人工复核可填写分值、改分与撤销；保留完整修订历史并拒绝陈旧版本覆盖。
- 匀变速、斜面、电路、波动四个理想模型支持预测—参数/输出记录—解释—新题验证；教师可对记录给出定性反馈，不用动画观看或文字长度判掌握。
- 方法视频、教材版本映射、AI 和班级连接按实际状态说明。学生提交回执请求失败不再显示为“未提交”，草稿保留，恢复后再核对。
- state v10、旧 `.pslab` 兼容保留；数据库新增草稿表，不清空旧数据；教师 PIN 增加错误尝试冷却。

**重要边界**：1,897 道内置完整题中，766 道与仓库内部教材节目录匹配，1,131 道仍待教材实本核验；不是教材授权或教师逐题审核结论。1,320 道有自动评分模式，577 道保持人工评分；四道多表征草稿仍未获教师审核。Windows 安装器未正式代码签名，Android APK 为本机开发签名。未完成真机跨设备课堂和教学效果验证。班级公网服务须单独部署；学生线上 AI 授权门禁不绕过。

SHA-256 见附件 `SHA256SUMS-v4.3.0-rc1.txt`。不要把此预发布版本当作正式商店发行版；旧标签和已发布版本保留。
